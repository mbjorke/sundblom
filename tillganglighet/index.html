Åland igår och idag

Tillgänglighetsredogörelse

Åland igår och idag (nudå.ax) strävar efter att följa WCAG 2.1 nivå AA — riktlinjerna för tillgängligt webbinnehåll utgivna av W3C. Den här sidan beskriver vad vi gjort, vad som ännu saknas och hur du kontaktar oss om du stöter på hinder.

Vad vi gjort

  • Semantiska HTML-landmarks: <header>, <main>, <nav>, <footer>
  • Hoppa-till-innehåll-länk synlig vid tangentbordsfokus
  • Synliga fokusindikatorer för tangentbordsnavigering
  • Dekorativa element markerade med aria-hidden="true"
  • Meningsfulla aria-label på navigeringskontroller
  • Tillräcklig textkontrast (minst 4,5:1 för normal text)
  • Responsiv layout som fungerar från 320 px bredd
  • Sidans språk angett i HTML (lang="sv")
  • Sidan fungerar utan JavaScript för grundläggande läsning

Kända brister

  • Den frakturstilta rubriktypografin (1920-talsstil) kan vara svårläst för vissa användare — det är ett medvetet stilval men vi undersöker alternativ
  • Boknavigeringen (klickbara kolumner) förlitar sig delvis på JavaScript; utan JS visas alternativ navigering i sidfoten
  • Arkivsidor genererade före mars 2026 saknar fullt uppdaterade landmarks

Rapportera ett tillgänglighetsproblem

Har du stött på ett hinder eller en bugg? Vi vill gärna veta om det. Kontakta oss via vår Slack-kanal eller via Blueberry.

Teknisk information

Sidan är statisk HTML genererad av ett Python-skript och hostad på Cloudflare Pages. Innehållet uppdateras automatiskt varje dag kl. 16:00 UTC. Källkoden är öppen och tillgänglig på GitHub.
